# Personal Portfolio

静的なHTML/CSS/JavaScriptで構成したトップページです。GitHub Pagesではリポジトリのルートを公開対象に設定してください。

## 起動方法

`index.html` をブラウザで開くか、任意の静的サーバーで配信します。例：

```bash
python -m http.server 8000
```

`http://localhost:8000` を開いてください。

## 構成

- `index.html` — セマンティックなトップページ
- `styles.css` — 漆喰を思わせる背景、タイポグラフィ、レスポンシブレイアウト
- `script.js` — JP / EN切り替えと状態保持
- `assets/` — プロジェクト画像
